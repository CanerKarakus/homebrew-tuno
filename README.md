# Homebrew Tap for Tuno

The missing controls for your Mac: per-app volume, HDMI volume, a system-wide equalizer, external display brightness, window switching and clipboard history, in one menu bar app.

```sh
brew install --cask canerkarakus/tuno/tuno
```

Tuno updates itself after installation. Requires macOS 15 or later on Apple silicon.

- Website: [gettuno.info](https://gettuno.info)
- Source code: [github.com/CanerKarakus/Tuno](https://github.com/CanerKarakus/Tuno)
